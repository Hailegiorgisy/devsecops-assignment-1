## Description
This repository contains the practical deliverables for Module One — DevOps & DevSecOps Foundations. It demonstrates the implementation of a secure pipeline baseline, environment variable isolation, and clean Git branching practices.

## Project structure
- `app/`: Application runtime entry point (`index.js`).
- `config/`: Configuration loader reading environment variables.
- `.gitignore`: Specifies deliberately untracked and sensitive files.
- `.env.example`: Sanitized schema template for required environment variables.
